# 👕 Clothing Store Sales & Profit Analysis

## 📌 Project Overview
An interactive Power BI dashboard to analyze clothing store sales, profit, quantity, and regional performance.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX

## 📊 Key Features
- Total Sales, Profit & Quantity KPIs
- Profit by State
- Sales by Payment Mode
- Quantity by State and City
- Monthly Sales Analysis
